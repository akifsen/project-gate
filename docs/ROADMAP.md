# Roadmap

V1 is the local evidence loop: contract, impact, six verifiers, selective re-verify, release packet, CLI, and MCP.

## Not in V1

- Hosted runners and a control plane
- Billing, SSO, and organization administration
- A product dashboard
- Native mobile and desktop testing
- Autonomous patch application
- Penetration testing
- A replacement test framework, browser engine, or accessibility engine
- Full HAR and video capture
- Node module resolution beyond relative imports
- Laravel container or service-container graphs
- Dynamic PHP calls that php-parser does not see as `use` statements or call expressions
- Architecture analysis of unchanged files
- A marketplace of verifiers

## Next, if a real change needs it

- More framework route adapters, still as impact plugins
- A human-approval evidence record with an explicit signer
- CI job examples for GitHub Actions and GitLab CI that only call the CLI and its exit codes
- Richer dependency edges where a false stale run is still preferred over a false fresh run
